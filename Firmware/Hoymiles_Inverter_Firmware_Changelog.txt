================================================================================
Scope: HM (1T/2T/4T), HMS (1T/2T/4T), HMT (6T).

HM-1T   V01.00.17 -> V01.01.00
  Added:
    - Control loop soft-foldback limiter (scales input down ~0.1x on overshoot).
    - Grid-frequency in-band debounce counter.
    - Explicit power-limit COMMIT sub-mode (0x40) in the 0x51 control path.
  Changed:
    - ePWM output config now runtime-switchable between two modes (was fixed).
    - 0x51 reply builders refactored.
    - RF re-join / backoff scheduling reworked.
  Removed:
    - Alarm-history read dropped its secondary latched/priority alarm table
      (now scans only the live event ring).
    - Hidden 0x30 / 0xFF selector no longer returns values over the NRF radio
      (confirmed on hardware): the command still parses, but its value-reply path was
      reworked so it emits nothing; the request now only drives internal actions.

HMS-4T   V01.00.27 -> V01.01.12
  Added:
    - DC-input fault detector, alarm code 223 (0xDF).
    - Power Distribution Logic (PDL v1): the per-input limit applier was replaced.
      1.0.27 split the limit into four equal quarters; 1.1.12 redistributes it
      proportionally across the producing inputs, with a 5-tick up/down ramp
      hysteresis, a controller-side 2% floor and a per-input -48 reconnect margin.
  Changed:
    - ActivePowerControl (0x51/0x0B) persistence bit: only type bit 1 (0x0002) makes
      a limit persistent. 1.0.27 persisted on any type bit except bit 0, so the
      HM-style 0x0100/0x0101 types are volatile from here on (0x0002/0x0003 persist).
    - Volatile-limit floor moved to 20 permille in the handler (was 0.02 fraction).
  Removed:
    - Nothing.

HMS-4T   V01.01.12 -> V02.00.04
  Added:
    - DevControl sub-command 0x22: "zero-export / DTU-loss management" parameters
      (enable, comm timeout in 0.1 s, fallback mode, ramp interval/step, fallback
      limit). Defaults: disabled, 10 s, mode 0 (zero output), 10% fallback. Writing it
      also applies the persistent limit and saves the record.
    - DTU-loss machinery: when enabled, a silent DTU forces the limit ceiling to 0
      (mode 0) or to the fallback limit (mode 1), with a ramp-up after recovery.
    - Compact "group control" command handler (gated by the same enable flag).
    - SystemConfigPara record type 3 (18 words / 36 bytes); an upgraded unit keeps
      answering type 1 until the first persistent write re-stamps the record.
    - PDL v2 in the controller: fair share over the inputs that actually produce (not
      /4), reduction taken only from inputs above their share, measured-power seeding
      on the first drop below rated, continuous commit after the 5-tick debounce,
      entry threshold +20 W (was +2 W), a config gate back to plain equal split, a
      zero-limit latch (<= 19 permille treated as stop), per-input 537 W cap, per-input
      ceiling parameters in RAM (were ROM).
  Changed:
    - ActivePowerControl 0x0B no longer writes the commanded value into the record
      word echoed by SystemConfigPara for volatile commands; the echoed limit is the
      persistent word only (default 1100 permille). Volatile limits still apply and
      persist in RAM until the next command or restart, but cannot be read back by any
      0x15 sub-command.
    - Handler-side 2% floor removed (the controller floor remains).
    - Two limit ceilings (rated ramp + soft-start/DTU-loss) instead of one.
    - 0x51 sub-command set: 0x06 (ACK only) and 0x22 added, 0x28 kept; 0x1E (state-2
      trigger), 0x1F/0x20 (GPIO test toggles), 0x21 (timed flag), 0x32 and 0xFF (Init)
    - Frame receive/validate and telemetry/record builder re-implemented.
  Removed:
    - MainCmd 0x31 dropped from the dispatcher.


HMS-4T   V01.01.12 -> V01.01.18 (Thailand)
  Added:
    - MainCmd 0x30 self-test / inspection command family (sub 0x00/0x01 start-stop
      flags, 0x02 + one parameter, 0x03 + five parameters, 0xFF abort); procedures
      1 and 2 with result tables read back through the 0x30 reply path.
  Changed:
    - Regional grid-code re-tuning (voltage/frequency trip limits; exact numbers
      not resolvable from flash).
    - Command layer is 1.1.x (bit-1 persistence, 20 permille floor, volatile limit
      echoed in SystemConfigPara).
  Removed:
    - PDL: the main-loop limit applier is the 1.0.x equal-quarter split. None of the
      1.1.12 PDL controller (hysteresis, -48 margin, redistribution) is present.


HMS-4T   V01.01.18 (Thailand) -> V01.01.29  (Thailand) (build 2026-08-25, model 0x1012)
  Lineage: 141 functions byte-identical with 1.1.18-TH, 80 with 1.1.12, 71 with
  2.0.04 -> 1.1.29 continues the 1.1.18 branch. The 2.0.x line is separate: none of
  its features (DevControl 0x22 DTU-loss management, type-3 SystemConfigPara, PDL v2)
  is present, and MainCmd 0x31 is still there.
  Added:
    - Self-test family (MainCmd 0x30) extended: new procedure 3, a state machine
      over the four DC inputs that drives the input switch GPIOs, waits up to 2000
      ticks per step and judges the result against thresholds taken from the 0x30
      sub 0x03 parameters (x0.1 and x0.02); 9-word result table. Procedure 2 (per-
      input measurement) re-implemented with a new executor; 17-word result table.
    - Real-time record: new status/flags word at record word 0x24 (procedure state
      bits from the 0x490/0x496 flag words and DC-input state bits). Whether the
      DTU-visible reply length includes it was not traced.
  Changed:
    - Reactive-power setpoint selection (Q modes 0-5): the model-specific corrections
      keyed on rated power (1600/1800/2000 W with fixed +/-6..50 offsets) were removed
      in favour of generic thresholds (0.72 / 0.21 of rated; -16 / +24 / +8 and
      -36 / -6 / +20); routine shrank from 1001 to 371 words.
    - Grid-support derating ramp (both channels): the event-recording side effect was
      taken out of the ramp step and a direction-locked clamp was added.
    - Parsed 0x50-tagged parameter record lost one 32-bit field (struct shifted by
      two words); task scheduler lost its one-shot callback slot; the mode-5 branch of
      the input-power scaling was removed.
  Removed:
    - MainCmd 0x52 sub-command 0x04 (three-word write into the device record, guarded
      by tag 0xFF07). Sub-commands 0x00-0x03 remain.
  Unchanged (relevant for DTU software):
    - Command layer is 1.1.x: 0x51 set incl. 0x1E-0x21, 0x32, 0xFF; no 0x22 / 0x06;
      0x15 set as in 1.1.18 (0x0C-0x0F gone since 1.1.18, no 0x17, hidden 0xFF
      selector present); ActivePowerControl persists on type bit 1 only, 20 permille
      floor, volatile limit echoed in SystemConfigPara (type-1 record).
    - No PDL: the main-loop limit applier is the equal-quarter split, as in 1.1.18.
    - Config-record layouts 1-4, temperature-derating floats F27-F29, alarm catalog.
